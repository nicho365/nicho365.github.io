Analisis churn pelanggan telekomunikasi

  • SQL
  • Python
  • Tableau
Lihat kode di GitHub
Masalah
Tingkat pelanggan berhenti berlangganan naik dan tim retensi belum tahu siapa yang perlu dihubungi lebih dulu.
Cara analisis
Membersihkan 7.000 data pelanggan, membuat segmentasi berdasarkan lama langganan dan pola pemakaian, lalu menguji faktor yang paling berhubungan dengan churn.
Hasil
Menemukan 3 segmen berisiko tinggi dan merekomendasikan penawaran kontrak tahunan untuk segmen terbesar.

Dashboard penjualan e-commerce

  • Power BI
  • Excel
  • SQL
Lihat dashboard
Masalah
Laporan penjualan dibuat manual setiap minggu di Excel dan memakan waktu setengah hari.
Cara analisis
Merapikan data dari beberapa sumber, membuat model data, lalu merancang dashboard dengan filter wilayah, kategori produk, dan periode.
Hasil
Laporan mingguan kini diperbarui otomatis dan tim dapat melihat produk dengan margin terendah tanpa menunggu analis.

Uji A/B promo diskon aplikasi

  • Python
  • Statistik
  • Looker Studio
Lihat laporan
Masalah
Tim marketing ingin tahu apakah diskon 15% benar-benar meningkatkan pembelian dibanding gratis ongkir.
Cara analisis
Menentukan ukuran sampel, membagi pengguna secara acak, lalu menguji selisih konversi dengan uji proporsi dan interval kepercayaan.
Hasil
Gratis ongkir terbukti memberi konversi lebih tinggi pada pengguna baru, sehingga anggaran diskon dialihkan.
