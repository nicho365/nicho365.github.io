# Nicholas Calvin | Data Analyst Portfolio

Live site: **https://nicho365.github.io**

Personal portfolio of Nicholas Calvin, a Data Analyst specializing in Business Intelligence. It showcases data analysis, machine learning, and design projects, along with certifications, work experience, and contact links.

## Project structure

```
index.html ----- Main page
landscape.html - Animated background, loaded inside index.html
assets/ -------- CV and other downloadable files
icons/ --------- Logos used on the page
img/ ----------- Project screenshots and images
```
